# 1주년 웹사이트 — 사용법

## 1. 설정 (index.html 상단의 `CONFIG`만 수정)

| 항목 | 설명 |
|---|---|
| `UNLOCK_AT` | 열리는 시각. 기본값 `2026-11-29T00:00:00+08:00` = **세부 자정 (한국 01:00)**. 한국 자정에 열고 싶으면 `+09:00`으로 변경 |
| `START_DATE` | 처음 만난 날 (`2025-11-29`) |
| `VIDEO` | 유튜브 링크 (아래 2번 참고) |
| `HER_NAME` / `FROM` | 받는 사람 / 보내는 사람 이름 |
| `MESSAGE` | 영상 아래 편지. 꼭 직접 쓴 말로 바꾸세요 ♡ |

## 2. 유튜브 영상
- 공개 상태는 **일부공개(Unlisted)** 로 올리세요. *비공개(Private)* 영상은 사이트 안에서 재생되지 않습니다.
- 동영상 설정 → **"퍼가기 허용"** 이 켜져 있어야 합니다 (기본값 켜짐).
- 링크를 소스보기로 들키지 않게 하려면 아래 명령으로 암호화해서 `VIDEO: "enc:..."` 로 넣으세요:

```powershell
$id = "여기에_영상ID_11자리"; $r = -join $id[($id.Length-1)..0]; "enc:" + [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($r))
```

## 3. 미리보기 (본인 확인용)
- `주소?preview=now` → 바로 열린 화면
- `주소?preview=10` → 10초 카운트다운 후 열리는 연출
